# インシデント対応ガイド

1. **検知・受付**: 発生時刻、報告元、観測した事実を記録します。
2. **初動評価**: 影響範囲、重要度、連絡・判断が必要な関係者を確認します。
3. **封じ込めと証跡保全**: 許可された手順で影響拡大を抑え、操作・時刻・証跡の所在を記録します。
4. **根絶・復旧**: 原因への対処、復旧手順、復旧確認、監視強化を記録します。
5. **再発防止**: 根本原因、是正・予防策、担当、期限、効果確認を合意します。

報告内容に推測を含める場合は、確認済みの事実と明確に分けます。外部連絡、法令上の対応、公開判断は組織の手順と権限者の判断に従います。
